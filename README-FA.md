# نسخه Cloudflare پنل فالور (مهاجرت اولیه)

این بسته یک پیاده‌سازی JavaScript برای **Cloudflare Workers + D1** است؛ PHP روی Workers اجرا نمی‌شود. فایل‌های CSS و JavaScript رابط قبلی نگه داشته شده‌اند و API جدید با Worker نوشته شده است.

## نصب

1. در Cloudflare یک D1 Database بسازید:
   ```bash
   npx wrangler d1 create follow-panel-db
   ```
2. مقدار `database_id` را در `wrangler.toml` جایگزین `REPLACE_WITH_YOUR_D1_DATABASE_ID` کنید.
3. جدول‌ها را بسازید:
   ```bash
   npx wrangler d1 migrations apply follow-panel-db --remote
   ```
4. رمز مدیریت را به‌صورت Secret تنظیم کنید (رمز دلخواه و قوی خودتان):
   ```bash
   npx wrangler secret put ADMIN_PASSWORD
   ```
5. نصب Wrangler و انتشار:
   ```bash
   npm install -g wrangler
   npx wrangler login
   npx wrangler deploy
   ```
6. آدرس `workers.dev` که Cloudflare می‌دهد باز کنید. دامنه اختصاصی را از بخش Workers & Pages به Worker متصل کنید.

## سرویس پیامک

پیش‌فرض API پیامک مطابق فایل تنظیمات پروژه PHP روی `https://api.siteesho.com/api/users` است. اگر سرویس شما متفاوت است، مقدار `SMS_BASE` را در `wrangler.toml` تغییر دهید. ارسال و اعتبارسنجی کد به دسترس‌بودن سرویس پیامک وابسته است.

## امکاناتی که در این پورت پیاده‌سازی شده‌اند

- ثبت‌نام/ورود با شماره موبایل و کد پیامکی
- نشست امن با Cookie و ذخیره نشست‌ها در D1
- داشبورد و نمایش موجودی، شناسه و کد دعوت
- گردونه شانس با محدودیت ۲۴ ساعته
- ثبت سفارش و کسر سکه با قیمت پایه مطابق منطق `domain.php`
- مشاهده سفارش‌ها
- انتقال سکه به کاربر با کد دعوت
- ثبت و مشاهده تیکت پشتیبانی
- تاریخچه تراکنش‌ها
- ورود مدیریت، آمار، مشاهده سفارش‌ها و کاربران، تغییر وضعیت سفارش، بازپرداخت سفارش لغوشده، تغییر موجودی، مسدودسازی کاربر
- نگهداری تنظیمات گردونه در D1

## مواردی که هنوز معادل کامل نسخه PHP نیستند

این بسته **مهاجرت کامل و هم‌ارز تمام ۱۱۵ فایل پروژه نیست** و نباید به‌عنوان نسخه نهاییِ بدون نقص معرفی شود. بخش‌های زیر در پورت فعلی پیاده‌سازی نشده یا نیازمند اتصال و تکمیل جداگانه‌اند:

- پنل کامل تنظیمات مدیر، کدهای هدیه، دعوت و پاداش دعوت، مأموریت‌ها، تخفیف‌ها، رسید پرداخت و مدیریت رسیدها
- سیستم کامل گفتگو/پاسخ‌دهی تیکت‌ها، اعلان‌ها و گزارش‌های مدیریتی
- انتقال داده‌های قبلی JSON به D1 (اطلاعات خصوصی کاربران و نشست‌های قبلی عمداً داخل ZIP قرار نگرفته‌اند)
- عملیات خودکار موتور روبیکا. فایل `auths.json` بنا به درخواست شما در بسته قرار نگرفته و هیچ توکن یا اعتبارنامه‌ای تعبیه نشده است؛ ثبت سفارش فقط سفارش را در وضعیت `pending` قرار می‌دهد تا مدیر بررسی کند.
- کپچای تصویری و محدودیت‌های ضدسوءاستفاده IP به شکل کامل نسخه PHP
- بازیابی/پشتیبان‌گیری سازگار با ساختار قدیمی

## نکات امنیتی

- `ADMIN_PASSWORD` را فقط با `wrangler secret put` تنظیم کنید؛ در کد یا فایل عمومی ننویسید.
- فایل‌های JSON، نشست‌های PHP، رسیدها و داده‌های کاربران از ZIP خروجی حذف شده‌اند.
- پیش از استفاده واقعی، سرویس پیامک، سیاست‌های نرخ درخواست، دامنه HTTPS و جریان مالی را آزمایش کنید.
- قیمت‌ها و تنظیمات پیش‌فرض در این پورت از مقادیر ثابت تعریف‌شده در منطق PHP گرفته شده‌اند؛ تنظیمات سفارشی `bot_config.json` به‌صورت خودکار منتقل نشده‌اند.

## ساختار

- `src/index.js` — Cloudflare Worker و API

- `public/assets/` — فایل‌های استاتیک رابط قبلی
